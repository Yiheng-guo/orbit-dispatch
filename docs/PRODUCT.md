# 星港调度：玩法与产品定义

## 玩家与核心体验

面向想在手机或电脑上短暂放松、愿意观察和规划的轻度解谜玩家。设定为深空能源调度员：通过旋转现有线路，把一束能源送达失联星港。

核心动作是旋转 90°；核心决策是哪些线路构成有效通路，以及应先调整哪里。调度次数带来轻度压力，不设置实时倒计时。

## 完整循环

进入 → 读懂目标 → 开始航程 → 观察端点与中继 → 旋转线路 → 看到能源传播 → 通联成功或调度耗尽 → 查看结果 → 下一关、撤销或重试。

金色能源与蓝色星港为固定端点。只有星港和所有中继站同时通电才获胜，未使用的线路可以保持断开。最后一次允许的旋转若接通目标，判为成功。撤销恢复棋盘和调度次数；提示记录不因撤销而消失。成功后不支持撤销，以免已保存星级和当前棋盘不一致。

## 范围与递进

六关依次引入直线、转弯、多中继、无关线路、长路线与折返。所有关卡开放，便于试玩比较和直接分享；星级保留同关最佳成绩，使用提示最多一星。三星步数是预设路线参考，未宣称全局最优。

支持键盘、鼠标和触屏。声音默认关闭，可主动开启；减少动态效果遵循系统偏好。不包含账号、联网对战、商业化或模型调用。浏览器本机存储被禁用时仍可游玩，但记录只在当前页面内保留。

## 学习假设

待实际试玩验证：初次玩家能在 60 秒内自主完成一次有意图的线路连接，并能解释中继站的作用。首轮邀请 5 名未看过开发过程的玩家，每人 5–10 分钟；观察至少 4 人是否能完成上述任务、至少 3 人是否主动进入第二关。阈值用于决定是否优先改教学和关卡，不能代表市场需求或整体玩家留存。

技术验收涵盖完整输赢循环、失败后的撤销重试、键盘与触屏操作、保存异常恢复、六关可解性、公开链接与子路径加载。体验假设与技术验收分别判断。
