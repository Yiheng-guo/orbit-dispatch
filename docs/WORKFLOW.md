# 从玩法到分享

本游戏使用 [PM Game Skills](https://github.com/Yiheng-guo/pm-game-skills) 提交 `8985633` 的以下方法：

| 技能 | 在本项目中的应用 |
|---|---|
| game-product-brief | 明确轻度玩家、旋转动作、中继目标、次数限制、完整输赢循环和学习假设 |
| game-engine-selection | 比较原生 DOM/SVG、Phaser 和 Godot，依据静态分享与回合制棋盘选择浏览器原生方案 |
| game-code-quality | 分离关卡、规则、展示和存储；定义终局优先级、撤销快照和异常恢复 |
| web-game-core | 语义按钮、相对模块路径、键盘与触屏输入、存储拒绝回退 |
| puzzle | 预设可解航线、互相对应的开口、完整撤销、有限调度和提示 |
| game-ui-ux | 目标、HUD、操作反馈、对话框与窄屏布局 |
| game-feel | 通电颜色、短反馈音、受系统减少动态效果设置约束的视觉反馈 |
| game-playtest-release | 完整循环与边界验证、本机反馈导出、独立真人试玩指南和公开链接交付 |

产品定义见 PRODUCT.md，技术取舍见 ARCHITECTURE.md，真人试玩方法见 PLAYTEST.md。浏览器自动测试不等同于真人体验结论，也不代表实体手机或所有浏览器兼容。
