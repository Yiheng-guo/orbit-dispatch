# 试玩指南

向未接触过项目的人发送公开游戏链接。只说“请接通第一段航线”，不先口头解释规则。每次 5–10 分钟，记录设备、浏览器、是否使用触屏及是否第一次接触接线解谜。

观察从打开页面到开始、第一次有意图连接、第一关完成所需的时间；记录是否理解中继站、何时使用提示、失败后能否恢复、是否主动进入下一关。不要把随机点击算作理解规则。

当玩家停顿时问“你刚才以为会发生什么”，记录实际原话与对应操作。结束后再询问最清楚和最困惑的地方，不用“是不是很好玩”引导答案。

游戏的“试玩反馈”支持导出最近 200 条本机操作记录和固定选项反馈。导出后由玩家自行交给开发者，没有自动上传。记录可辅助定位问题，不能替代观察、完整会话时长或用户访谈。

首轮决策参考：5 名新玩家中至少 4 人在 60 秒内完成有意图连接且能解释中继作用，至少 3 人主动进入第二关。未达到时先调整规则说明、视觉可读性或第一关；达到后再扩大测试。样本很小，不能据此推断总体留存率。

技术自动测试与触屏模拟不属于真人试玩。物理手机、Safari、Firefox 和长期存储行为需要各自执行验证。
